# Portfolio

Personal developer portfolio built with React, TypeScript, Vite and Tailwind CSS.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- ESLint
- Prettier

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/vallinah/portfolio.git
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```

## Available Scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```

Format the project with Prettier:

```bash
npx prettier --write .
```

Check formatting:

```bash
npx prettier --check .
```
